**✅ Voici la liste SIMPLIFIÉE « jour après jour »**  
Tous les éléments qui influencent **production / consommation / humeur du client** en boulangerie artisanale française (basé sur Bridor Baromètre 2025 + études FEB/INSEE + patterns réels météo-saison).

### **LUNDI**
- **Consommation** : +5 à +12 % global (réapprovisionnement post-week-end). Pain de mie, pains spéciaux, sandwichs.
- **Météo** : Pluie/nuageux → + confort (pains longs conservation). Ensoleillé → - viennoiseries. Neige/froid → + chocolatines.
- **Humeur client** : Routine familiale, un peu fatigué → achat « utile » et rapide.
- **Heures pics** : 7h30-9h (baguette) + 11h30-13h (sandwich).
- **Production** : Plus de pains classiques, moins de viennoiseries festives.

### **MARDI & MERCREDI**
- **Consommation** : Stable (±5 %). Mercredi = pic viennoiseries enfants.
- **Météo** : Toutes conditions → impact faible.
- **Humeur client** : Routine scolaire/travail. Mercredi = « jour des enfants » (plus gourmand).
- **Heures pics** : 7h-9h + 12h-13h.
- **Production** : Baguette classique + viennoiseries pour enfants.

### **JEUDI**
- **Consommation** : +7 % si pluie (anticipation week-end). Stable sinon.
- **Météo** : Pluie → + sandwichs / pains à tartiner.
- **Humeur client** : Fin de semaine qui approche → un peu plus d’achats plaisir.
- **Heures pics** : 11h30-14h + 17h-19h.
- **Production** : Préparer plus de snacking et viennoiseries pour le soir.

### **VENDREDI**
- **Consommation** : +10 à +18 % (début week-end + souvent jour de paye fin de mois).
- **Météo** : Toutes → boost général.
- **Humeur client** : Bonne humeur, envie de récompense → plus de viennoiseries et snacking.
- **Heures pics** : 7h30-9h30 + 17h-19h (très fort).
- **Production** : Augmenter viennoiseries + pains spéciaux.

### **SAMEDI**
- **Consommation** : +15 à +25 % (meilleur jour de la semaine).
- **Météo** : Pluie/nuageux → pic maximum. Ensoleillé → + snacking/tourisme.
- **Humeur client** : Famille détendue, marché, sorties → achat plaisir + quantité.
- **Heures pics** : 8h-11h (énorme).
- **Production** : Tout en hausse, surtout viennoiseries & pâtisseries.

### **DIMANCHE**
- **Consommation** : +18 à +30 % (matin uniquement).
- **Météo** : Toutes → très fort le matin.
- **Humeur client** : Moment familial / rituel → baguette fraîche + viennoiseries.
- **Heures pics** : 7h30-10h30 (le rush absolu).
- **Production** : Focus matin massif – beaucoup de baguettes + viennoiseries.

### **FACTEURS TRANSVERSAUX (à flagguer chaque jour dans Levain)**
- **Vacances scolaires** (zones A/B/C 2025-2026) :  
  - Été (juil-août) → -10 à -25 % urbain / +15 à +40 % zones touristiques.  
  - Toussaint/Noël/Hiver/Printemps → +15 à +30 % avant + pendant.  
  - Mercredi & samedi en vacances → +20 % viennoiseries enfants.
- **Jours fériés & ponts** → +20 à +35 % la veille + jour même (rush fort).
- **Fin de mois / jour de paye** → +8 à +12 % (surtout vendredi).
- **Événements locaux** (marché, fête de village, match) → +30 %.
- **Température extrême** : >25 °C → - viennoiseries au beurre / + snacking léger. <5 °C ou pluie forte → + pains réconfort.
- **Saison** : Août = mois le plus faible en ville. Décembre/janvier = pics fêtes.
